# Enterprise Linux Administration & Automation Suite

## 📌 Overview
This project provides an automated **Shell Scripting Suite** for Red Hat Enterprise Linux (RHEL) environment. It handles automated user onboarding, security auditing, log rotation, and automated backups.

## 🛠️ Key Linux Concepts Covered
- **User & Group Administration:** `useradd`, `groupadd`, `chmod`, `chage`, permissions management.
- **Process & System Monitoring:** `ps`, `find`, `df`, `cron`, text processing with `awk` and `grep`.
- **Archiving & Compression:** `tar`, `gzip`, log maintenance.
- **Automation:** Shell Scripting, Cron Automation, I/O Redirection.
